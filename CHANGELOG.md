# Changelog

## 2.2.2

- Restricted the background extension to the canvas so drawing content reflects under the glass sidebar without duplicating the editor toolbar into the title area.

## 2.2.1

- Added Restore All and confirmed Delete All Permanently actions in Recently Deleted, with visible storage errors.
- Applied Liquid Glass to deleted-note controls, the selection panel, the welcome New Note button, sidebar surfaces and custom swipe actions, with material fallbacks on older iPadOS versions.
- Aligned bulk-selection controls in equal columns and moved Search, Edit and Restore Backup into a dedicated three-dot popover.
- Set the sidebar's minimum, preferred and maximum widths to 350 points and hide it when drawing or scrolling the canvas, using an overlay layout to avoid resizing ink mid-stroke.
- Added a compact, tappable title for renaming and corrected the editor's deletion message to describe Recently Deleted.
- Replaced the Notion setup compass with a scalable Notion logo that adapts to light and dark appearances.

## 2.1.3

- Set explicit adaptive text colors on GitHub, Patreon and feedback rows for readable links in light and dark appearances.

## 2.1.2

- Added colorful accents to Home, Settings, setup instructions and note actions.
- Gave GitHub, Patreon and feedback separate tap targets, with bundled brand icons and a compact Patreon shortcut beside Settings.
- Enlarged the creator signature and added a random emoji every 0.4 seconds, respecting Reduce Motion and app activity.
- Added in-app email feedback with an external-mail option and a copy-address fallback.
- Darkened the dark-mode handwriting canvas and added a persistent dotted-paper toggle in Settings and the editor. Guides follow scrolling and stay out of exports and Notion sync.

## 2.1.1

- Expanded the note icon collection and added a searchable picker with persistent choices.
- Added selected-note animation with Reduce Motion support.
- Added title search, sorting, pinned notes, and Recently Deleted with restore.
- Added creator information and email feedback in Settings.
- Updated light and dark app icons, documentation, and MIT licensing.

## Earlier releases

Introduced local PencilKit notes, editable backups, Notion image sync, sidebar selection, bulk actions, and automated unsigned IPA releases.

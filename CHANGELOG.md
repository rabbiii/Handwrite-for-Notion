# Changes

## 1.1

- A monochrome light/dark palette with native Liquid Glass controls on supported systems.
- One continuous, vertically extending PencilKit canvas per note with fixed horizontal width.
- A horizontally scrollable floating toolbar containing undo, redo, finger drawing, clear canvas, save, export, destination selection, sync, autosync, settings, and note actions.
- Clear Canvas supports undo and redo while the note remains open.
- One variable-height image per note, with a Notion-dark background and unchanged ink colors. The image height follows the lowest stroke.
- Optional autosync starts after half a second without canvas activity. Uploads are serialized and changes made during an upload remain editable and are queued for the next sync.
- Older paged notes are joined in order while preserving editable PencilKit strokes and a previous local save.
- A new monochrome notebook-and-pencil app icon.

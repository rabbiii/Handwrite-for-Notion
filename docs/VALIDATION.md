# Validation and limitations

Portable tests cover storage envelopes, recovery, backup import, metadata, geometry, and mocked Notion operations. Native simulator tests cover PencilKit rendering, migration, saving, and interface previews.

A passing build does not establish physical-device performance or complete interaction coverage. Verify Pencil input, icon picker layout, swipe controls, bulk selection, app icon appearances, and real Notion sync on an iPad before relying on a release for important notes.

This project has not undergone an independent security audit. Report vulnerabilities privately to mar.rabbi40@gmail.com and omit secrets from public issues.

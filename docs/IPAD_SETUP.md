# Start using PencilNotes

Install a signed build, open the app, and tap **New Note**. Write with Apple Pencil or enable finger drawing. Notes save locally; Notion is optional.

Tap a note icon to change it. Search the sidebar by title, use Library to sort notes, and long-press a row to pin it. In Edit mode, tapping a row selects it for bulk actions. Tap outside the sidebar to finish selection.

The minus control closes the current note after saving. Deleted notes can be restored from Library ? Recently Deleted until permanently erased.

Export **Editable Backup** files regularly. Restore Backup imports a separate note and clears its Notion link, so it does not overwrite the original remote image.
